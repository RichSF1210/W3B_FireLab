EXPERT STRETCH: WRITE YOUR OWN BUILDING BLOCK

These three scripts are unfinished exercises. Each one makes one part of a fire
from code, and each has a STRETCH note inside.

Goal: make a new sound for Layer 3 of Campfire B, written by you.
Where to start: open one of these scripts, or copy NoiseLayer.cs and rename the
class (the class name must match the file name). Everything happens in
NextSample(): the one place a sample is made, about 48,000 times a second.
What success sounds like: a part of the fire that is not just noise through a
filter: for example a slow swell, a cluster of snaps, or a pitched hiss.
Push further: make your sound respond to Intensity (the "intensity" value, 0 to 1).

Safety: start with the computer volume low, and take your headphones off for the
first Play after every code change.
